Vchange

简洁美观的 Windows 视频转换器 · 内置完整 ffmpeg · 向导式操作 · 深浅色主题自适应

⬇ 立即下载 Vchange GitHub 查看源码
Windows 10/11 单文件免安装 内置完整 ffmpeg 深浅色自适应

核心特性

为日常视频转换而生，专注体验与效率

🎬

向导式转换流程

选择文件 → 输出格式 → 视频参数 → 码率 → 开始转换，步骤清晰，随时可返回修改。

🎛

灵活的转换参数

编码、分辨率、帧率、码率均可单独设置，或一键勾选「与原视频相同」。

⚡

硬件加速编码

支持 NVENC (N卡)、QSV (Intel核显)、AMF (A卡) 等硬件加速，转换又快又省电。

🌓

主题自适应

深色/浅色界面跟随系统自动切换，应用图标同步切换，护眼更舒适。

📊

实时进度反馈

进度条显示百分比与实时转换速度，转换日志实时输出 ffmpeg 原始输出。

📦

开箱即用

单文件绿色版，无需安装 .NET 运行时，内嵌完整版 ffmpeg，首次转换自动释放即可使用。
